# ENEZA Data Science Internship Project

| | |
| --- | --- |
| **Tentative title** | Use of citizen-science data to unravel some key insect-host plant interactions |
| **Abstract** | Increasingly citizen science-based documentation of biodiversity information through photo documentation is gaining momentum. Open-source applications such as iNaturalist and e-bird are widely used tools to document biodiversity. Some of the main advantages of this approach are availability of georeferenced data, possibility of interaction data (flora and faunal relationship) and temporal information on when the documentation was undertaken. However, the shortcomings of this approach include weak identification information especially for smaller organisms and lack of systematic observation of the data. The availability of interaction data provides an opportunity to establish some key relationships between insects and their host plants and prevailing ecological conditions. In the proposed internship, the candidates will extract data on fruit flies and thrips and their associated host plants from the iNaturalist platform. The data will be cleaned for accuracy and then analyzed for host-pest interactions and suitability of ecological conditions. Phenomenon such as thrips and fruit fly aggregations and its relationship with diversity of host plant on which it occurs will be assessed. |
